# MCGOOD

Página en español sobre Minecraft con seis guías, filtros y una lista de progreso guardada localmente en el navegador. Sitio estático adaptable a móviles; no requiere instalación de dependencias.

## Ejecutar

Desde este directorio:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Abre el sitio con tu navegador. También puedes servir los archivos con cualquier servidor estático. Las fuentes de Google son opcionales: hay fuentes alternativas locales.

El progreso pertenece al navegador y no se sincroniza entre dispositivos. La información puede variar según la edición y versión del juego. Proyecto de fans sin afiliación con Mojang o Microsoft.
